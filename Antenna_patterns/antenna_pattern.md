# Antenna Radiation Patterns

This folder contains the horizontal (azimuth) and vertical (elevation) radiation patterns of the transmit antenna used in the Buffalo CBRS deployment.

The .pat files contain the original antenna radiation-pattern data obtained from the manufacturers' technical documentation, while the .csv files provide the same numerical values in a structured format, with angle (degrees) and normalized antenna gain (dB).

No additional normalization or modification was applied during CSV conversion.

The CSV files provide the numerical values of normalized antenna gain (dB) as a function of angle (degrees).
